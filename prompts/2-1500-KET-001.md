# 需求：1500 个 KET 单词 → 100 个学习句子（含 CSV 与 PDF）

## 0. 输入与产出

- 输入：`1500-KET/1500-KET.csv`，1500 个 KET 必会单词（列：英文,音标,词性,中文；单词 id = 数据行号）。
- 产出（全部文件组织在 `1500-KET/` 目录下；数据与 PDF 文件名一律带项目前缀）：
  1. `1500-KET/1500-KET-sentences.csv` —— 100 句学习数据（10 列，见第 5 节）；
  2. `1500-KET/1500-KET-sentences.pdf` —— A4 打印版；
  3. `1500-KET/plan/plan001.md` —— 执行计划（先写计划再动手，每次迭代生成新的 plan 编号）；
  4. `1500-KET/worklog.md` —— 生成过程与选择逻辑复盘。

**数量口径**（全文档唯一）：100 个句子、1500 个单词、平均每天 15 个词。每天新学 12–18 个词，其中真实出现在句中的 8–15 个，其余进"扩展必背词"（见第 1 节）。

## 1. 单词覆盖规则（硬约束，机器可校验）

**术语**（后文一律按此用词，不得混用）：

- **新词**：本句（本天）负责的词表词；
- **句中新词**（`new_words` 列）：新词中真实出现在英文句里的那些；
- **扩展必背词**（`extend_words` 列）：新词中为避免句子冗长、句型难组织而不进句子，改用"同类 / 反义 / 词族"成组集中背的那些。

1. **先分配、后写句**。当前词表按字母顺序，直接每 15 词切一段并不合理。先产出"词分配表"：把 1500 词按语义家族与主题重新分组（星期、月份、季节、颜色、数字与序数、身体、家庭、食物、动物、文具、运动、职业、国家与国籍、天气、方位、节日、交通工具，以及反义对、前缀/后缀派生词族等），再铺到 100 天上。要求：
   - 尽量均匀：**每天新学 12–18 个词**（建议贴近 15），100 天合计恰好 1500 个；
   - 同一家族尽量落在同一天或相邻天（只有落在同一天才进得了同一句的扩展组）；
   - 学习顺序与词表 id 顺序解耦：**id 小的词不一定先学**。因此全文"旧词"一律指**更早天数学过的词**，与 id 无关；
   - 排词时把语法进阶的需要考虑进去（如 there、when、because 等词要排在对应语法上线之前）；
   - 单句词数允许与相邻句做 ±1 微调，但必须记入 plan 与 worklog，且总覆盖不变。
2. **扩展必背词**（本版新增，用于给句子减负）：
   - 例：Monday, Tuesday, … Sunday 这一类，句子里出现其中一个（如 Monday），其余 6 个放进本句"扩展必背词"。颜色、月份、数字、季节等同理——句子不冗余，使用者照样知道每个词怎么用；
   - 组织依据艾宾浩斯：优先成"同类词、反义词、前缀/后缀派生、近似词"的组，让使用者按规律成批记，并顺带复习旧词；
   - **锚词必须在句中**：每个扩展组都挂在本句 `new_words` 里的某个词上，并在 `extend_note` 写明（如"星期名（锚词：Monday）"）；
   - 组里可以混入**更早天数学过的词**做对比复习（反义词、同族词等）：这些词不计入本句覆盖、不写进 `covered_ids`；
   - **每句扩展必背词总计不超过 10 个词条**（含复习旧词），超了就拆到相邻句；不要为了"多复习"把使用者压垮。
3. **100 句覆盖全部 1500 词**：每个词恰好被分配一次（出现在某句的 `new_words` 或 `extend_words` 中，且都在该句 `covered_ids` 里），无遗漏、无重复、无表外词。
4. 每个**句中新词**必须真实出现在英文句中；复数、三单、-ing、过去式、比较级等变形允许，`new_words` 列记原形；词表自带变形标注（如 pl. children）视为合规。**扩展必背词不要求在句中出现**（但锚词必须在）。
5. 除本句新词外，句子建议使用：
   - **更早天数**学过的旧词（**鼓励**自然重复旧词，这是复习设计的一部分）；
   - 必要功能词；
   - 白名单专有名词（见第 2 节主题设定，需在 plan 中显式列出，如角色名、地名）。
6. 不得引入词表之外的其他实词。
7. 句子长度：句中新词 8–15 个（建议 10–13）决定了句子比小学版长，建议 15–30 词，**鼓励使用复合句**（状语从句、宾语从句、定语从句入门），既容纳新词又贴合 KET(A2) 句型。允许"一句 = 两个关联短句"的结构，但仍按 1 个 id 计数。
8. 扩展必背词是**要背的**：它随所在那天的卡片进入滚动回读（第 4 节），并在 PDF 卡片上单独成块（第 6 节），不能只藏在 CSV 里。

## 2. 句子内容与主题

1. 100 句要有连贯性和故事性：选定一个适合 KET 学习者（小学高年级至初中）的主题，在 plan 中设计分幕故事线（建议 8-10 幕）并贯穿始终。
2. **若借用现成作品（如哈利·波特）的角色/世界观，角色定位必须与原作一致**（上一版教训：哈利·波特是孤儿却写成"和妈妈对话"、霍格沃茨没有英语/数学/体育课、海格并不老却被叫"老海格"）。词表词与设定冲突时，用翻译加注做"本土化/魔法化"处理，或把场景放在作品之外（如入学前的麻瓜学校回忆），并在 worklog 说明取舍。
3. 句子要有意义、有画面感，可化用名著语感，不照抄原文长句。
4. **逻辑合理性校验（生成后必查）**：
   - 搭配自然（反例：pink football——粉红色足球不合常理）；
   - 人物关系一致（谁在说话、对谁说，符合设定）；
   - 时间/季节/场景一致（如生日在夏天就不出现滑冰课）；
   - 前后句情节衔接自洽。
5. 扩展组也要过一遍合理性：一组里的词必须真属同类/反义/同族（反例：把 red 和 Monday 凑成一组），且组说明与成员对得上。

## 3. 语法/句型进阶

1. 覆盖 KET(A2) 主要语法场景，由浅入深排布（plan 中给出分幕语法表），建议主线：
   - 第 1-2 幕：be 动词、祈使句、there be、介词、疑问句（复习性起点，KET 考生有基础）；
   - 第 3-4 幕：一般现在/现在进行、频率副词、情态动词 can/must/have to；
   - 第 5-6 幕：**一般过去时**（KET 核心）、时间表达、将来时 will / be going to；
   - 第 7-8 幕：比较级/最高级、现在完成时入门、被动语态入门；
   - 第 9-10 幕：状语从句（because/when/if）、宾语从句、间接引语入门、综合复习。
2. 每句的语法讲解用中文写 1-3 句，只讲本句实际出现的语法点，不泛泛罗列。
3. 句型与学习顺序冲突时，服从词分配表（上一版教训：there be 句型必须等 there 成为新词后才能使用）。语法需要什么词，就在分配表里把它排到那一幕之前——这正是第 1.1 条"先分配、后写句"要解决的问题。

## 4. 复习设计（滚动艾宾浩斯，硬约束）

1. **滚动回读**：采用间隔 **1、2、4、7、15、30 天**。第 d 天（d ≥ 2）的回读任务 = { d-1, d-2, d-4, d-7, d-15, d-30 } 中 ≥ 1 的天，写在 review_note 开头："今日回读：请重新朗读背诵第 X、Y、Z 天的句子。"（Day 1 无回读。）
   - 例：Day 8 回读 Day 7、6、4、1；Day 16 回读 Day 15、14、12、9、1。
   - 每个句子恰好被后续 6 天回读；**不允许**把回读任务固定钉在某几个"复习日"上（上一版曾因此返工）。
   - 回读文案由脚本统一生成并机器校验，不手写。
   - **扩展必背词随所在那天的句子一起回读**：卡片上的扩展块与生词表同等对待，回读时要一起过。
2. **回读要求：朗读 → 背诵 → 背写**。先朗读，再合上书背诵整句，有时间就默写（背写）一遍，写错的词重点练。新学句子的每日流程同样以背诵 + 背写收尾。这一点必须写进 PDF 的使用说明页。
3. **自然复现**：非回读层面，每句尽量自然编入旧词（**扩展必背词也算已学词**，可以被后续句子直接使用），review_note 在回读句之后记录本句实际复现的旧词及出处天数；扩展组里的复习旧词同样要标出来源天数。
4. 首要原则是句子本身的合理性与故事性，复习安排在此之上叠加。

## 5. 1500-KET-sentences.csv 格式（硬约束）

- 编码 UTF-8 带 BOM（方便 Excel 打开）；用 python csv 模块读写，字段含英文逗号/引号/换行时必须正确加引号。
- 表头 + 100 行，每行恰好 10 列：

| 列 | 内容 |
|---|---|
| id | 1-100（= 第几天学习） |
| sentence_en | 英文句子 |
| sentence_zh | 中文意思 |
| grammar | 语法/句型讲解（中文，简明） |
| new_words | 本句**句中新词**（真实出现在句中的，8-15 个）：`词\|音标\|词性\|中文`，多个用 `; ` 分隔；音标/词性/中文照抄原词表（词性为空则留空） |
| extend_words | 本句**扩展必背词**（可为空）：同一组内条目用 `; ` 分隔，组与组之间用 ` \|\| ` 分隔；条目格式同上；整句合计 ≤ 10 个词条 |
| extend_note | 各组说明，用 `；` 分隔、与 `extend_words` 的组一一对应，如 `星期名（锚词：Monday）；反义词复习：happy（第 12 天）`；`extend_words` 非空时必填，每组 ≤ 20 字 |
| phrases | 1-3 个短语：`短语\|中文`，`; ` 分隔；短语只能由已学词 + 本句新词构成 |
| review_note | "今日回读：…"（脚本生成）+ 本句自然复现的旧词说明（含扩展组里的复习旧词来源） |
| covered_ids | 本句新词 id（`new_words` + 扩展组中的新词），逗号分隔；**扩展组里的复习旧词不计入** |

- **已知陷阱（必须写进 plan 提醒所有执行者）**：音标内部可能含 `; `（如 `/duː; də/`）和逗号，任何下游解析不得按 `; ` 简单切分 `new_words` / `extend_words`，必须按 `covered_ids` 对照原词表取词条；组间分隔 ` || ` 同理。

## 6. PDF 排版（1500-KET-sentences.pdf）

1. **前两页为书名 + 使用说明（Howto）**：第 1 页约 35% 为标题区（书名大标题、副标题、"1500 词 / 100 句 / 分幕数 / 100 天"关键信息），其余 65% 与第 2 页为 Howto，内容至少包括：这本书怎么用（每日步骤，以**背诵 + 背写**收尾并标为最重要）、**扩展必背词怎么用**（同类词/反义词/词族成组背，与生词同等重要）、每天回读（滚动艾宾浩斯原理与举例）、单词安排（先分组分配、学习顺序与词表顺序无关）、故事线、语法进阶、卡片结构说明、给家长的小建议。Howto 控制在 2 页以内、易读。
2. Day 1 卡片从第 3 页开始；每个句子一个卡片：Day 标题 → 英文句（大号、醒目柔和的主题色）→ 中文 → 语法讲解（淡色背景）→ 生词表（每行恰好两个，含音标/词性/中文，颜色区分词形/音标/词性）→ **扩展必背词（另起一块，用与生词表不同的淡色底；组说明作小标题，条目每行两个，复习旧词标注来源天）** → 短语表（同样每行两个）→ 蓝色"今日回读"条 → 重现旧词小字。`extend_words` 为空时该块整块省略。
3. 字号适合孩子 A4 打印阅读：英文句 ≥ 16pt、正文 ≥ 11.5pt、语法/生词 ≥ 10.5pt；卡片 `break-inside: avoid`，流式翻页、每页约两张卡片，**不允许大面积空白**（页底留白 ≤ 20% 为宜）。
4. 页眉（书名）+ 页码；中文与 IPA 音标必须正常显示（声明支持 IPA 的字体回退链，如 DejaVu Sans）。
5. 渲染后逐页转图抽查（首页、Howto 页、中间页、末页）：无乱码、无方框、无大面积空白、每行两个生词、扩展块样式与生词表可区分。

## 7. 流程要求（防返工，逐步留痕）

1. 先写 `plan/plan001.md`（**词分配表**：每天的词条清单与扩展组表（组说明/锚词/成员/来源天）、分幕故事线、语法进阶表、白名单、CSV 格式、复习规则），再开始生成。
2. 分批生成（建议每批 10 句），**每批写完立即落盘**（独立批次文件，避免并发/中断丢失），全部批次完成后合并为 1500-KET-sentences.csv。
3. **机器校验脚本（必须通过后再排版）**：
   - 结构：100 行 × 10 列，id 1-100 连续，UTF-8 带 BOM；
   - 覆盖：1500 词每个恰好被分配一次（`new_words` + 扩展组新词），无遗漏、无重复、无表外词；每天新学词 12-18 个；
   - 每个 `new_words` 词（含常见变形）真实出现在对应英文句中；
   - `new_words` / `extend_words` 的音标/词性/中文与原词表逐字一致（按 `covered_ids` 对照验证）；
   - 扩展块：整句条目 ≤ 10，组数与 `extend_note` 说明条数一致，每组锚词 id ∈ 本句 `new_words`，组内复习旧词的 id 必须属于更早天数且不在 `covered_ids`；
   - 用词顺序：句中内容词必须 ∈ {本句新词} ∪ {更早天数的词} ∪ {闭类功能词} ∪ {白名单专名}；
   - 每行回读文案与滚动规则 {d-1, d-2, d-4, d-7, d-15, d-30} 完全一致。
4. 内容校验（第 2.4、2.5 条清单）通过后渲染 PDF，转图目检。
5. 写 worklog.md：记录生成过程、单词分配（含扩展组的组织逻辑）、句子/短语/语法选择逻辑、复习设计、踩坑与修订历史。
6. 每个文件生成/重大修改后单独 commit + push。
